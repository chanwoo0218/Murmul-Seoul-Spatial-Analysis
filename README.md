# 머물로 서울: 블록 단위 잠재소비 분석

> Dasymetric Mapping으로 역세권 상권 매출을 블록 단위로 재배분하여, 현재 매출은 낮지만 교통·보행·상업 인프라를 고려할 때 소비 잠재력이 높은 공간을 찾은 공간 데이터 분석 프로젝트입니다.

## 개인 기여도

- 기존 역세권 단위 분석이 상권 내부의 공간 이질성을 충분히 반영하지 못한다는 문제를 구체화했습니다.
- 상권과 도시 블록의 교차 폴리곤을 구성하고, 보행·대중교통·도로·POI·건물 수용력 지표를 결합한 공간 분석 파이프라인을 구축했습니다.
- Min-Max 정규화와 상권 내부 가중치 재정규화를 적용해 원래 상권 총매출을 보존하면서 블록 단위 잠재매출을 산출했습니다.
- IQR 기반 기회지역 탐지와 Spearman, R², IoU, Moran's I, 후속시점 매출 비교를 통해 결과를 검증하고 해석 범위를 재정의했습니다.

## 연구 질문

기존 역세권 단위 분석은 상권 내부의 보행 흐름, 교통 접근성, 상업시설 밀도와 건물 수용력 차이를 하나의 평균값으로 처리합니다. 이 프로젝트는 다음 질문을 검증했습니다.

> 상권 내부의 공간 이질성을 반영해 매출을 블록 단위로 재배분하면, 이후 실제 매출이 증가할 가능성이 높은 잠재 소비 공간을 식별할 수 있는가?

## 분석 아이디어

상권 전체 매출을 면적 비율로 균등 배분하면 상업활동이 발생하기 어려운 공간에도 같은 잠재력이 부여됩니다. 이 프로젝트는 보행·버스·지하철·도로 접근성, 상업 POI 밀도, 건물 수용력을 보조변수로 사용해 상권 매출을 블록 단위로 재배분했습니다.

1. 모든 보조지표를 Min-Max 정규화
2. 블록별 상업활동 점수 구성
3. 상권 내부에서 가중치 합이 1이 되도록 정규화
4. 원래 상권 총매출을 보존하며 블록 잠재매출 배분
5. 잠재매출과 관측매출의 양의 격차가 큰 블록을 IQR 기준으로 선별

## 검증 설계

- Spearman·Kendall 상관: 순위 일치도
- R²: 후속 매출과의 설명 일치도
- IoU@상위 10%: 고잠재·고성과 블록 중첩
- Moran's I: 공간적 군집성
- 후속시점 매출 비교: 잠재력이 실제 이후 성과로 이어지는지 확인

## 정량적 결과

### 후속 매출 예측력

| 지표 | 결과 |
|---|---:|
| Spearman 순위상관 | 0.28~0.36 |
| R² | 0.12~0.14 |
| 기존 baseline 개선 | 0/15 |
| IoU@상위 10% | 14.8~24.0% |
| 성장 상위 20% AUC | 42~54% |

후속 실제 매출과 약한 양의 관계는 확인했지만, 미래 매출 예측값으로 사용하기에는 설명력과 분류력이 제한적이었습니다.

### 공간 구조의 안정성

| 지표 | 결과 |
|---|---:|
| POI Spearman 평균 | 0.9689 |
| Weighted IoU 평균 | 86.67% |
| 실제 매출 Moran's I | 0.15~0.25 |
| 잠재 매출 Moran's I | 0.80~0.88 |

POI 기반 공간구조는 높은 순위·중첩 안정성을 보였으며, 잠재매출은 실제 매출보다 강한 공간 군집을 형성했습니다. 검증 결과를 바탕으로 산출값을 미래 매출 예측치가 아니라 **상권 내부 잠재수요를 진단하는 공간 보조지표**로 재정의했습니다.

## 데이터 공개 기준

ZIP의 모든 파일을 검토했습니다. 공개데이터 중 소규모 원본·집계파일과 분석 노트북은 포함했습니다. 다음 대용량 원자료는 저장소 용량과 배포 관리 문제로 직접 포함하지 않고 `data/README.md`에 원본 파일명과 배치 경로를 명시했습니다.

- 시간대별 지하철 승하차 원자료
- 행정동 추정매출 원자료
- 역-상권 전체 매핑 테이블

내부망 경로·비밀번호 예시가 포함된 병합 노트북, 빈 실험 노트북, 중복본은 공개 대상에서 제외했습니다.

## 실행 방법

```bash
pip install -r requirements.txt
python scripts/reassemble_data.py
jupyter notebook
```

노트북의 개인 PC 절대경로는 `../data/external`과 `../outputs` 기준 상대경로로 변경했습니다. 대용량 외부 데이터를 `data/external/`에 준비한 뒤 순서대로 실행하세요.

## 한계

- 잠재매출은 관측값이 아니라 보조지표로 재배분한 추정치입니다.
- 가중치와 공간 단위 선택에 따라 결과가 달라질 수 있습니다.
- 세 역세권의 결과를 서울 전체로 일반화하기 어렵습니다.
- 관찰자료 분석이므로 정책의 인과효과를 직접 증명하지 않습니다.
